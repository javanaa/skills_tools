## 1. Phase 流程补充判据
- Phase1 提取六类：几何（每层材料/尺寸/单位一个不落）、激励与边界、求解器设置、设计公式、benchmark 指标、**隐式假设**（论文没说但影响复现：导体损耗算了吗？基板无界吗？端口去嵌说明了吗？）。
- Phase1.5 公式预扫雷在建模**前**做（见 §3），别在笔误上浪费几小时 CST。
- Phase4 分析前先出图文汇报（§8），再进深度对比。
- 一次 run 可复现：同 run 目录保留源工程、脚本、参数表、CST 版本、求解器、频段、状态标签。

## 2. paper-parser：model_spec.yaml 字段契约
产出物 = `model_spec.yaml`（结构化参数，直接喂建模）+ `paper_notes.md`（公式解读/存疑点）。字段：
```yaml
geometry:    # 每层介质{材料,εr,tanδ,厚度}；每金属结构{形状,尺寸变量,位置}；地{有限/无限,尺寸}
excitation:  # 端口类型/阻抗/边界条件/对称面
solver:      # 类型/频段/网格类型与密度/收敛标准
formulas:    # 论文设计公式+变量含义+适用范围
benchmarks:  # S11谐振频率/最小值/带宽；方向图增益/波束宽/副瓣；效率
assumptions: # 隐式假设逐条记录（如"端口去嵌未说明"）
info_completeness: green|yellow|red
```
**信息完整度评级**：绿=正文+图片交叉验证通过可直接建模；黄=个别缺失需假设补齐（assumptions 记录）；红=关键信息缺失（无结构图/看不清）→ 联系作者或换论文，不硬猜。

## 3. paper-formula-falsify：五类硬伤 × 四步 × 四实验
**只查 2-4 个承重公式**（算法核心步骤/创新点/决定可复现性的），review 公式与标准定义跳过。
| 硬伤类别 | 典型症状 |
|---|---|
| ①笔误 | 上下标抄错→照字面实现矩阵秩退化为 1 |
| ②符号重载 | 同一符号多处含义不同→数据流说不清 |
| ③约束不等价 | 闭式解反推≠声称目标（最深，常藏这里）|
| ④算法不收敛 | 循环终止条件不可达 |
| ⑤量纲/域 | 等式两边量纲不一致、dB 与线性混用 |
四步：定位承重公式 → 三视角纸面审计（符号一致性/量纲域/约束目标等价性）→ 数值证伪 → 汇总报告。
四类标准证伪实验：字面实现退化检测（验笔误）、反例构造（验约束不等价）、论文参数复算（验声称值）、参数敏感性扫描（验适用边界）。**最小化原则**：N=2 能说清就不用 N=20。
严重度四级：CRITICAL（阻断复现，必勘误）/ MAJOR（数学不成立，需证明或改措辞）/ MINOR（漏报边界，补讨论）/ CLEARED（查过没问题，明确记录）。
**铁律：MAJOR/CRITICAL 必须至少跑 1 个数值实验才能定级；纸面只能给"疑点（待验证）"。CLEARED 要写出来**——防重复怀疑、诚实推翻纸面担忧。
产出：`formula_audit_report.md` + `falsify_*.py` + PNG。

## 4. 求解器选型决策树（cst-modeling-guide，2025 实测）
- **宽带天线首选 T-Solver（时域）**；**窄带/高精度首选 F-Solver（频域）**——注意这与 playbook §3"吸波单元周期单元走频域四面体"不矛盾：吸波体 S11 窄带关注点+四面体混合网格场景走 FD，宽频天线走 TD；先按问题形态选，不照搬。
- ⚠️ 宽带插值陷阱：F-Solver 扫频默认有理函数拟合整条曲线，**尖锐窄凹陷可能是拟合伪影非真实谐振**；疑似窄谐振处必须加密采样或用 TD 对照。
- **双求解器交叉验证（论文级铁律）**：先校准后信任——TD/FD 先在简单校准结构（均匀波导、馈电过渡段）上对齐，再信复杂装配体；TD 门槛=求解 success+稳态收敛判据满足+功率闭合可接受；**非收敛曲线只能诊断，不得参与变体排名**；TD/FD 大分歧先查端口口径（过窄会人为制造假分歧，先扩口径再怀疑物理）。
- 端口六纪律：从**物理横截面**定义端口（微带波导端口必须含地+基板+带线+带线上方足够空气）；不假设带线宽=50Ω，读 CST 实算参考阻抗；过渡结构（微带-SIW 等）先独立校准再接整机；多模端口 TE/TM 标签三方核对（截止频率+端面场图+mode order），不确定按索引标注并声明映射 pending；"additional propagating mode not considered"警告=诊断旗标，先加模式数再判断；阵列快速评估可全阵独立端口+均匀幅相激励跳过馈网。
- 对称面：电场垂直对称面用 Electric(Et=0)，磁场垂直用 Magnetic(Ht=0)。
- **场监视器是硬约定**：求解**前**必须定义标准套件（远场+E 场+H 场含表面电流+坡印廷），频点≤3 个（中心必选+带边/谐振点 1-2）；缺场数据不许静默跳过，汇报里如实写"本批未加（原因）"。

## 5. 17 条 2025 实测坑（cst-em-sim，全文要点级）
1. `Solver.Method` 有效值是 **"Hexahedral"** 不是 "Time Domain"。
2. 网格密度 VBA 命令**全部静默失效，唯一旋钮是 Fmax**（十三轮探针实锤）：加密=抬 Fmax；缩规模防内存崩=压 Fmax（单元数 ~(Fmax比)³）；网格档位以实测单元数 n_cells 为准，不信命令自报。【对应 C2】
3. 倾斜面/楔形 = Polygon3D+ExtrudeCurve，首点重复为末点闭合。
4. 多 DE 实例 COM 路由混乱（SaveAs 失败根因）→ 单实例独占铁律。
5. `start_solver()` 抛 "Unknown error" 时改 `run_solver()` 看真实错误。【即 C1 的 Python 层语境；VBA 层 FDSolver.Start 不冲突】
6. 后台任务约 10 分钟被环境强杀，长时求解需 GUI 手动或远程委托。
7. 导入 STEP/IGES/CAD 必须走 `add_to_history`，不能走 `_execute_vba_code`。
8. 中文路径让 CST Python 加载失败。
9. S11/1D 导出四坑：批量 ASCIIExport 攒 history 会全导成当前选中项——每条独立导出。
10. 材料定义 VBA 有实测唯一正确写法（见 cheatsheet）。
11. 几何查询 API 有怪癖，返回值不可全信。
12. 多段波导四坑：共面贴合 Solid.Add 并集**静默丢件**（体积缺失、S21 全反射）；Polygon3D 绕向随参数升/降序翻转；**新建工程默认边界不是 electric**（闭合波导须显式六面 electric）；亚毫米相切薄片伪结构。
13. 远场方向图导出四坑：3D 远场不能直接 ASCIIExport；plot 类命令 add_to_history 重放=空操作；`_execute_vba_code` 顶层必须包 `Sub Main()...End Sub`；切面导出唯一可靠路线=单个 Sub Main 内**原子执行** plot+export（分步会抓到默认切面）。
14. 远场无头导出五坑：quiet 模式绘图引擎不加载远场数据（一切 plot 类命令出空图）；开 GUI 跑远场 Plot 会**死锁**（DE CPU 冻结）；无头全 3D 唯一路线=quiet 裸 `ASCIIExportAsSource`；`CopyFarfieldTo1DResults` 恰好 2 参数；`prj.close()/de.close()` 可段错误击杀 python（finally 不执行→锁+DE 双泄漏）。
15. TD"最大脉冲宽度数"会截断长路径板级仿真 → 求解后读 Result/output.json 判 steady_state（truncated/ok）。
16. 跨机 SSH 委托大模型求解：非交互会话挂起 → 需计划任务注入交互会话；笔记本插电（BatteryStatus=2）；每任务独立进程+watchdog。
17. 3D 场点云导出三坑：ASCIIExport 缺 `.Step(采样步宽)`=导出零数据（文件正常生成但只有表头）；结果树叶子名带 `[N]` 运行号后缀必须枚举拿真名；3D 场走结果树 quiet 可导（与坑 14 远场不同）。

## 6. 开工/收尾纪律 + 结果状态标签
**开工纪律**（独占防冲突）：启动前先 `Get-Process` 查 CST* 占用；另一会话在跑 → 排队等待，绝不并行第二条 DE 链；杀进程前先判归属（有无用户 GUI 会话/其他并行任务），不确定=不杀。
**收尾纪律**：SaveAs 完成后显式 cleanup（项目 cst_config.cleanup_cst() 标准函数）；汇报只给产出路径不叙述过程；多变体/扫参批次收尾必出图文汇报（§8）。
**结果状态标签（7 类，每份汇报末尾必附）**——`.cst` 工程只是模型不是证明，"几何已重建+端口/模式确认+求解成功完成+真实导出在手"四条件全满足才算 validated：
`CST-validated` / `CST-incomplete`（证据链不完整）/ `CST-regressed`（本次完整求解比历史权威结果差，**如实标退步，不许只挑好看的**）/ `model-built-not-solved` / `CST-not-applicable` / `analytic-only` / `pending-verification`。缺 CST 导出时说"对比 pending"，绝不拿解析/插值曲线补位冒充 CST 结果。

## 7. 视觉自查规范
建模后截四图：3D 全貌 / 侧视（层叠）/ 俯视（形状）/ 端口特写，逐项与论文结构图对比（形状、馈线位置、基板比例、端口位置）。出图后自查渲染：文字裁切/图例遮挡/批注压曲线。能力边界：能读趋势与标注、查渲染质量；**不能**像素级测尺寸（~0.1mm 误差）、不能精确数字化曲线点（需 WebPlotDigitizer 类工具）。关键尺寸永远优先正文数值，图只管空间关系；模糊标注记 `info_completeness: yellow`。曲线读数仅作交叉验证参考，正式对照以 Phase1 文字记录为准。

## 8. 图文汇报五步（cst-result-report 流程）
Step0 状态盘点（PowerShell 查进程为准，Git Bash tasklist 会 GBK 漏报；`*_solved/Result/` 的 simulation_overview.json+MCalc.log 尾部+Model.res mtime 三件判求解活跃度；results/*.txt 的 mtime=导出时间≠求解完成时间；**先找历史已完成导出再宣布新最优**）→ Step1 指标提取脚本化（不手抄旧笔记）→ Step2 四件套图（最佳 vs 论文叠加/扫参分组全景≤4条一子图/结构演进对比/场分布三件套）→ Step3 论文对照拼接图 → Step4 质检（图逐张视觉抽查；md 图片路径存在性校验）→ Step5 写 md（固定章节：⚡验收速览四要素表置顶/一页概览+状态标签/复现对照（偏差 <1%✅、1-10%⚠️、>10%❌）/场分布章（硬约定）/各任务详细/事件簿/文件索引）。
图内标签一律英文（自带 matplotlib 无中文字体）；图片必须 `![说明](相对路径)` 内嵌不许裸给路径；引用路径不含括号/空格。

## 9. 三方验证判据（em-verification）
论文声称值 ↔ 理论解析值 ↔ CST 仿真值，按指标逐项对齐（谐振频率/S11 最小值/10dB 带宽/增益/波束宽/副瓣）。
偏差 = |参考−仿真|/|参考| ×100%：**绿 <5%（复现成功）/ 黄 5-15%（需排查）/ 红 >15%（建模或论文有问题）**。
黄/红逐项溯源六查：几何尺寸→材料 εr/tanδ→网格收敛→边界物理匹配→端口与去嵌→论文是否美化。
常见偏差归因：谐振频率偏→εr 或边缘场；带宽偏宽→损耗算少；增益偏低→导体损耗/端口失配；S11 形貌差异大→几何偏差。产出 `verification_report.{json,md}`，明确"哪些能复现/哪些有偏差/偏差原因"。
（对齐 SKILL.md P5：三方缺其二只写"趋势参考"。）
